# model-cache

Mirror of publicly released ONNX model weights, re-hosted as release assets so
downloads are pinned to a known file and SHA-256.

Nothing here is modified from its upstream release. Each file keeps its upstream
license; check it before any use beyond personal research.

| File | Upstream | License |
|---|---|---|
| `glintr100.onnx` | [insightface](https://github.com/deepinsight/insightface) model zoo, `antelopev2` pack (ArcFace IResNet-100, Glint360K) | Non-commercial research only (insightface model license) |

Hashes are listed on each release.
